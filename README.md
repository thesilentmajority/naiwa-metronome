# 奶娃节拍俱乐部

一个适合手机练琴的趣味动画节拍器。

- 30–240 BPM，2/4、3/4、4/4、6/8 拍号
- 摇摆、蹦跳、列队三种奶娃动画
- 细分节奏、重音、敲击测速、练习计时
- 手机底部播放控制、安全区域适配、记住练习设置
- 纯静态网页，不需要服务器或账号

## 使用
打开 `index.html`，点击开始练习。手机保持网页在前台，后台或锁屏时浏览器可能暂停声音。支持的浏览器会在练习时保持屏幕点亮。

## GitHub Pages
将本目录的文件上传到仓库根目录。在 Settings → Pages 中选择 Deploy from a branch，分支选择 main，目录选择 / (root)，保存。

## 素材
奶娃角色图片由项目发起者提供。本仓库不额外授予角色形象的使用许可。
